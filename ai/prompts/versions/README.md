# ChinaTrip AI Prompt Versions

本目录保存正式 Prompt version 的行为档案。

每次修改 `TRAVEL_ANSWER_PROMPT_VERSION` 时，必须新增对应文档，记录：

- Version ID 和状态。
- 改动目标。
- 影响模块和 PromptProfile。
- 已知风险。
- 必须通过的 Harness case。
- 发布或回滚结论。
