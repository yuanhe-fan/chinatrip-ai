# ChinaTrip AI 六期：答案反馈与关联追问

## 目标

每条已完成 AI 答案在聊天页提供轻量反馈与下一步探索入口：

- 👍 / 👎 不要求登录，按当前登录用户或匿名会话保存；首次成功提交后锁定。
- 👎 点击后先填写可选原因与最多 500 字补充说明，仅在点击“保存”时写入。
- 答案完成后异步生成 1 至 3 条强相关问题，不阻塞主回答流。
- 点击关联问题后在当前聊天中直接生成回答，始终跳过 Trip setup。

## 边界

- 反馈不显示全局计数，不进入 Prompt、RAG 或分享快照。
- 关联问题保存在 assistant message metadata，不新增业务表。
- 首期只在私有聊天页展示；公共分享页不展示反馈或关联问题。
- 生成失败时隐藏关联问题，不影响答案、分享、复制或后续聊天。

## 验收

- 已完成答案可提交一次反馈，刷新后恢复选中样式且不能再次修改。
- 👍 立即保存；👎 原因和补充信息只在点击“保存”后提交。
- 不同用户或匿名会话互不覆盖反馈。
- 生成中、失败答案和 quick question 菜单不显示反馈模块。
- 关联问题返回 1 至 3 条，已有 metadata 时不重复调用 AI。
- 包含行程规划关键词的关联问题也直接回答，不请求澄清问题。
